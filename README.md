# DocuMind AI

منصة Streamlit لفهم المستندات واستخراج المعلومات منها. النسخة الحالية تعمل محليًا بدون مفتاح API، وتستخدم بحثًا دلاليًا خفيفًا واستخراجًا تلقائيًا للنص والملخص والبيانات المهمة. ويمكن تفعيل نموذج متوافق مع OpenAI اختياريًا.

## المميزات

- رفع PDF وTXT وMD وDOCX.
- استخراج النص مع رقم الصفحة/الموضع.
- تلخيص استقرائي سريع، أو تلخيص عبر نموذج خارجي عند ضبط المتغيرات.
- سؤال المستند واختيار المقاطع الأكثر صلة مع إظهار المصدر.
- استخراج التواريخ، البريد الإلكتروني، أرقام الهاتف، والعبارات ذات الصلة بالأسماء.
- قاعدة SQLite لحفظ سجل الملفات والأسئلة.
- واجهة عربية RTL مع تبويب للمستند الحالي والسجل.

## التشغيل

```bash
python -m venv .venv
# Windows
.venv\\Scripts\\activate
# Linux/macOS
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

افتح الرابط الذي يظهر في الطرفية، غالبًا `http://localhost:8501`.

## تفعيل نموذج خارجي اختياريًا

انسخ `.env.example` إلى `.env` وضع `OPENAI_API_KEY`، ثم عدّل `OPENAI_API_BASE` و`OPENAI_MODEL` إذا كنت تستخدم مزودًا متوافقًا. التطبيق يعود تلقائيًا للمحرك المحلي إذا لم توجد المفاتيح أو حدث خطأ.

## هيكل المشروع

- `app.py`: واجهة التطبيق.
- `src/document_engine.py`: القراءة، الفهرسة، البحث، التلخيص والاستخراج.
- `src/database.py`: طبقة SQLite.
- `tests/`: اختبارات بسيطة للمحرك.
- `data/documind.db`: تُنشأ تلقائيًا عند أول تشغيل.

## ملاحظات

المحرك المحلي لا يدّعي التعرف الكامل على الأشخاص؛ استخراج الأسماء heuristic ويحتاج مراجعة بشرية في المستندات الرسمية. عند استخدام نماذج خارجية، راجع سياسة الخصوصية قبل رفع مستندات حساسة.
